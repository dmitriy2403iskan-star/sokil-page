# MK15 — исследование собственной Android-платформы

Цель проекта — исследовать возможность создания отдельной системной платформы Android для SIYI MK15. Целью **не является APK**: приложение может использоваться только как временный макет интерфейса, если это понадобится для проверки дизайна.

## Что известно об устройстве

Согласно ранее полученному диагностическому отчёту:
- Qualcomm MSM8953 / board msm8953;
- Android 9, API 28;
- Linux kernel 4.9.112;
- ARM64;
- экран 1776×1080;
- около 2 ГБ RAM.

Эти сведения описывают устройство, но не доказывают, что доступна полная исходная аппаратная поддержка для независимой сборки Android.

## Подход

1. Составить карту подтверждённых характеристик устройства и неизвестных компонентов.
2. Изучить общую архитектуру AOSP 9 и требования к совместимости.
3. Проверить наличие открытых исходников и публичной документации, не предполагая, что найденный код подходит MK15.
4. Описать системный интерфейс, настройки, приложения и пользовательский сценарий.
5. Оценить, можно ли получить воспроизводимую тестовую сборку в безопасной изолированной среде.
6. Отдельно документировать варианты резервного копирования и восстановления, не выполняя операций на устройстве.

## Ограничения текущего этапа

- Никаких изменений на самом пульте.
- Не стирать штатную систему и не менять загрузчик или разделы.
- Не создавать и не устанавливать прошивку для аппаратного тракта управления.
- Не взаимодействовать с закрытыми службами производителя, MCU, радиоканалом или USB-протоколами.
- Не считать резервную копию проверенной, пока не подтверждены её полнота и реальная возможность восстановления.

## Текущий статус

**Этап: исследование платформы.** До доказательства совместимости никакая сборка не считается пригодной для установки на MK15.

См. [PLATFORM_RESEARCH.md](PLATFORM_RESEARCH.md) для первичной оценки и списка неизвестных.
