# MK15 Controller Analyzer

Исходный Android-проект диагностического приложения для SIYI MK15. Проект находится в каталоге `mk15-controller-analyzer/`.

**Важно:** репозиторий публичный. Здесь нет секретов или личных данных. Приложение предназначено для диагностического сбора доступной Android-информации; оно не читает serial-порты и не меняет настройки пульта.

Сборка APK запускается через GitHub Actions при push. Готовый APK будет доступен в Artifacts у соответствующего запуска workflow.
